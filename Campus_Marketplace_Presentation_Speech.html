💡 9. Panel Q&A Quick Answers Cheatsheet

Q on Member 1 (Campus Filtering): How does filtering execute?
"Uses in-memory & Firestore queries matching listing.university against the active campus state, falling back to 'All Campuses'."
Q on Member 2 (Chat): How are messages structured in Firestore?
"Root conversations collection with participant IDs in a memberIds array, and an inner messages subcollection ordered by createdAt server timestamps."
Q on Member 3 (Storage): Where are image files stored?
"Images are binary blobs uploaded to Firebase Cloud Storage under listing-images/{uid}/{timestamp}; only the public download URL string is stored in Firestore."
Q on Member 4 (Modal Fix): Why did the review button get stuck previously?
"Native Android Dialogs cannot stack without trapping focus. Solved via internal view routing in a single modal with smooth back navigation."
Q on Member 5 (TypeScript): How did TypeScript benefit the team?
"Declaring strict interfaces in types.ts ensured 5 developers worked concurrently on isolated files with zero runtime type mismatch errors."
